# Quick Start: Products vs Services

## 🚀 TL;DR

### Adding a **PRODUCT** (📦)
```
Dashboard → Add Product → Toggle to 📦 Product → Upload image → Set stock → Save
```

### Adding a **SERVICE** (🔧)
```
Dashboard → Add Product → Toggle to 🔧 Service → ✅ Skip images → Save
```

---

## Side-by-Side Comparison

|  | PRODUCT | SERVICE |
|--|---------|---------|
| **Icon** | 📦 | 🔧 |
| **Examples** | Snacks, books, clothes | Tutoring, design, repair |
| **Images** | ✅ Required | ❌ Skip |
| **Stock** | ✅ Required | ❌ Auto |
| **Delivery** | ✅ Checkout → Delivery | ❌ Messaging |
| **Payment** | Collection / Cash / Card | Negotiated |
| **Customer Action** | "Add to Cart" | "Message Seller" |

---

## How It Works

### PRODUCT Flow
```
Customer browses
    ↓
Sees image + price
    ↓
"Add to Cart"
    ↓
Checkout (pick delivery)
    ↓
You prepare + deliver
    ↓
Customer receives ✅
```

### SERVICE Flow
```
Customer browses
    ↓
Sees name + price + description
    ↓
"Message Seller"
    ↓
You negotiate in messages
    ↓
Agree on time/details
    ↓
You deliver service ✅
```

## Common Issues

### ❌ "Can't upload image"
**For PRODUCTS:** Must upload ≥1 image (max 2MB each, JPG/PNG/WebP)
**For SERVICES:** Images not needed - skip upload field

### ❌ "Service won't save"
Make sure you **toggled to 🔧 Service** first!

### ❌ "Products not showing"
- Check stock > 0
- Set status to AVAILABLE
- Wait a moment for sync

### ❌ "Services not appearing"
- Go to Services page (not Marketplace)
- Make sure product type is SERVICE
- Check if category is set
